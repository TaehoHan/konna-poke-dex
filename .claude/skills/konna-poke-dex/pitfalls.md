## 폰 앱 (Flutter + ONNX Runtime) — 티니핑 앱을 포크하면 그대로 해당
- [겪음] **`flutter_onnxruntime.createSessionFromAsset` 는 모델을 고정 이름으로 한 번만 꺼내 재사용한다.** 새 모델인데 옛 모델이 돌아 라벨과 어긋났다. 모델 내용 해시 파일명으로 꺼내 `createSession(path)`.
- [겪음] 같은 이미지에서 파이썬 ONNX 결과와 앱 결과가 다르면 앱의 모델·라벨·전처리를 의심한다. 출력 번호 오프셋이 라벨 차이와 맞으면 옛 모델이다.
- [겪음] iOS 카메라 프레임은 이미 회전돼 온다(회전 0). Android 는 센서 방향 그대로(미검증).
- [겪음] 근접 초점: 초광각 + 2× 확대. 탭 초점·핀치 확대.
- [겪음] iOS 무료 서명은 번들 ID 가 겹치면 안 된다 → 티니핑 앱과 **다른 번들 ID** 를 쓴다. `flutter build ios --release` 후 `xcrun devicectl` 로 설치·실행.
- [예상] 1026 클래스 라벨·도감 DB 가 커지면 앱 시작이 느려질 수 있다 → 도감 DB 는 지연 로드.

## 음성 (TTS 클로닝) — 티니핑에서 겪은 것, 다른 목소리에도 그대로 해당
- [겪음] 레퍼런스의 **앞 0.25초가 광대역 잡음**이면 생성 음성 앞에 쉬익 소리가 붙는다. 잡음 감소 + 앞부분 자르기 사본으로 클로닝(스펙트로그램으로 확인).
- [겪음 2026-10-25] 레퍼런스 영상에 **배경음악·효과음**이 계속 깔리면 무음 구간이 없고(-27dB) 스펙트로그램에 가로줄(지속음)이 보인다. afftdn 은 음악을 못 지운다 → demucs(htdemucs) 목소리 분리로 무음 구간 -70dB. 모델은 드라이브 `Models/hf-hub`(HF 캐시 구조, 심볼릭 링크 없이 실제 파일)에 두고 `HF_HUB_CACHE`+`HF_HUB_OFFLINE=1` 로 쓴다. demucs `--repo` 는 `.th` 만 읽어 safetensors 를 못 쓴다. demucs 는 실행마다 결과가 조금 다르다(차이 -46dB, 정상).
- [겪음 2026-10-25] 짧은 레퍼런스(7초)보다 15초 전체가 고유명사 발음이 나았다("이상해씨" CER 0.44 → 0.00).
- [겪음 2026-10-25] `build-audio.py` 의 유성음 기준 앞뒤 자르기(voiced_span)가 **이름·문장 끝을 잘라 먹었다** (마스카나 "마스카나." 통째로, 최대 1.46초). 레퍼런스가 demucs 로 깨끗하면 쉬익 소리가 없으니 `--no-voice-trim` 으로 -45dB 무음만 자른다(최대 0.79초, 말소리 손실 없음). 후처리 뒤에는 원음 대비 줄어든 길이 상위 몇 개를 받아쓰기로 확인한다.
- [겪음] 같은 시드라도 레퍼런스가 바뀌면 억양·속도가 달라진다. 새 목소리로 바꾸면 시드·temperature(0.5) 후보를 여러 개 만들어 사용자가 고르게 한다.
- [겪음] 받아쓰기(CER)는 고유명사에서 틀린다 → 의심 목록용. [예상] 포켓몬 이름(이상해씨, 파이리…)은 더 자주 틀릴 것.
- [겪음] 쉼 없는 문장은 "가장 조용한 150ms" 수치가 높게 나오지만 잡음이 아니다. 수치로 단정하지 말고 A/B 샘플로 듣게 한다.
- [겪음] 한 번에 하는 동적 loudnorm 은 조용한 구간(숨소리·잡음)을 키운다 → 2패스 선형.
- [겪음] TTS 가상환경(`.venv-tts`)과 학습 가상환경은 분리한다. 학습과 합성을 동시에 돌리면 서로 느려진다.
- [예상] 1025문장 합성은 수 시간 → 없는 것만 합성(재실행 안전), 단계별로 나눠 돌린다.

- [겪음 2026-10-25] 세레비넷 SV 목록에 **지역(팔데아) 도감 번호**가 섞여 84종에 다른 종 설명이 붙었다(캐터피 ← 맛보돈). 받은 페이지는 **페이지 안 National 번호로 종을 확인**한다. 번역본은 (class_id, source_text) 가 원본 flavor_en.json 에 있는지로 걸러 205항목을 지웠다(백업 workspace/tmp/flavor-ko-translated.before-sv-fix.json).
- [겪음 2026-10-25] 한 종 페이지에 같은 게임 설명이 여러 개면 폼(메가·리전·품종·모자 피카츄) 설명이다. 폼 이름 없이 넣으면 기본형 설명으로 잘못 보인다 → 번역 항목에 `form` 태그를 붙여 넣고(`flavor_ko[].form`), 앱은 그 폼을 볼 때만 보여 준다. 음성(make-text)은 폼 설명을 쓰지 않는다.

## 저장소·운영
- [겪음] `git add -A` 가 가상환경·생성물을 스테이징한 적이 있다. 커밋 전 `git diff --cached --name-only | grep -E "\.(jpg|png|webp|onnx|pt|zip|parquet|npy|json)$"` — 특히 `pokedex-ko.json`(도감 원문), `kaggle.json`(토큰), `*.wav`(레퍼런스·생성 음성).
